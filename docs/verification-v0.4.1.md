# v0.4.1 修复验证

## 儿童端本地视频布局

根因：推荐页外层 Stack 默认 loose，只按非 Positioned 的顶部导航计算高度；Positioned.fill 内的播放器跟随这个窄高度收缩，导致视频、右侧操作、文案及进度一起挤到顶部。修改为 StackFit.expand，导航改为顶部 Positioned；保留视频原比例与底部导航。

- 儿童端版本 0.4.1+6，debug APK 已打包。
- Flutter analyze 无问题，儿童端 7 项测试通过。
- 新测试直接实例化完整 KidsHome（模拟接口、离线目录与原生解码），覆盖 390×844 手机和 1280×720 电视、1080×1920 竖片和 1920×1080 横片，包含在线本地上传目录、离线缓存及切换导航后返回。
- 断言 PageView 占满内容区、视频中心与页面中心重合、保持片源比例、标题处于下半屏、导航居顶、进度居底；不是仅测试独立叠层。
- 测试截图位于 runtime/ui/kids-page-*.png，使用占位背景，无真实家庭视频。已目视检查手机横竖两种情况。
- 本次未发现已连接 ADB 设备，因此尚未在实体手机覆盖安装。
- Android 工程没有 web 目标，未进行 Flutter Web 构建。

## 抖音导入

实际提供的分享链接可解析为作品 7696507927519875953。F2 0.0.1.7 的详情请求返回 HTTP 403；进程却 exit 0 且没有 MP4，本机 F2 没有 Cookie。旧适配器仅检查进程退出码和 MP4 数量，错误把所有无输出都提示为图集。

- 独立临时数据目录、127.0.0.1:18765 启动新版 Go HTTP + worker，经真实 API 提交同一个链接，任务正确提示抖音拒绝访问及登录配置操作。未修改家庭主数据库。
- 子进程适配器保留最近 64KB 内存诊断用于固定分类，绝不返回原始输出。区分 403/401、429、404、超时、真正图片输出、无文件和多视频。
- 文件命名改为作品 ID，关闭附属原声/封面/文案，避免长标题形成 Windows 超长路径。
- 每次任务自动发现数据目录 private/f2.yaml，FAMILY_F2_CONFIG 优先；不要求每次设置登录状态后重启。
- scripts/configure-douyin.ps1 支持隐藏输入或显式读取剪贴板，只写本机配置，PowerShell 语法检查通过。
- Go 16 项测试及 vet 通过，包括真实子进程模拟 exit-0 403、单 MP4、多 MP4、真实图片及零输出、运行后新增配置文件、固定错误不回显上游 Cookie。
- 用户提供抖音登录 Cookie，已仅保存到忽略的本机私有配置；原 PyPI F2 配置登录后仍返回 403。固定上游 v0.0.1.8-pw3 分支提交 f6be8c0ffba9a127075bbeafe4838716650b6325 后，实际下载得到 36,845,513 字节 MP4；ffprobe 检查通过，HEVC、1920×1440、413.547 秒。
- 已更新下载器依赖锁及当前隔离环境；同时将运行中的 v0.4 服务所用下载器默认配置同步为本机登录状态、ID 命名和单条下载默认值，旧 worker 已直接重试，但之后的视频源请求仍返回 403。新 Go 服务仍优先读取 runtime/private/f2.yaml。
- 另用 yt-dlp 2026.10.21 交叉验证，有 Cookie 仍提示新 Cookie；未作为生产依赖加入，旧试用环境保留在 runtime 备份中。
- F2 真实下载已验证成功；Go 完整下载、处理及入库回归的最终结果见下方追加记录。

当前家庭主服务仍为 v0.4.0。新版服务端已构建为 bin/family-video.exe 及 bin/family-video-v0.4.1.exe；需要用户停止旧服务后启动新版，未重复尝试此前被自动审批拒绝的停止替换操作。

- 用户提供的登录信息仅写入忽略的本机配置；不写入源码、文档或依赖锁。
