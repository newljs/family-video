# v0.4 地址直连验证

- 家长端、儿童端版本均为 0.4.0+5。两端只输入服务器地址，不再输入管理密钥、配对码或设备名称。家长端移除生成配对码、设备授权及撤销入口。
- Go 取消 Bearer 身份验证及设备注册依赖，新安装只生成内部媒体签名参数。旧数据库和旧签名参数继续使用；旧配对端点返回 410。
- 目录按公开的客户端类型区分家长/儿童展示。儿童和匿名目录只返回已发布视频；媒体链接继续检查发布状态与签名。局域网管理接口免认证。
- Go 全部 13 项测试及 go vet 通过。包含无凭证连接和管理、未发布过滤、媒体 Range、下架阻止播放、旧设备凭证不再参与身份判断。
- 共享 API 的 4 项测试、家长端 3 项测试、儿童端 3 项测试均通过；三个 Flutter 包分析无问题。
- 共享 API 验证旧 token 不进入请求头，旧服务提示更新，失败连接保留地址，断开重连保留历史缓存标识。
- 两端 debug APK 已成功打包。Windows 服务端 bin/family-video-v0.4.exe 已构建，并在独立临时数据目录及 127.0.0.1:18765 完成健康、匿名儿童、家长目录类型和无凭证任务接口检查。
- 原 8765 服务仍运行 v0.3.0：自动审批拒绝停止并替换旧服务（blocked by policy），没有修改该进程。需要手动停止旧服务并启动新版 EXE。
- 未在实体安卓平板或电视上安装验收，真实抖音链接下载仍未验证。
