# TV v0.1 验证

本轮新增 `apps/tv_app` 独立原生 Android 客户端，最低 API 21，与既有 Flutter 客户端共用 Go 服务。测试使用合成的无个人内容视频和隔离数据目录，不修改家庭媒体库。

## 自动检查

- TV JVM 测试：遥控循环与合集顺序、安静合集覆盖、失败视频全部耗尽时停止、播放/暂停/缓冲/跳转计时、稳定事件重试与确认、未上报时长纳入额度、跨视频归属、手输地址、发现地址范围、HTTP 儿童角色和 no-store、媒体代理前缀与观看事件载荷。
- Android lint 检查 API 21 兼容性；构建压缩的 trial APK。旧依赖版本、中文单语文案、TV 固定横屏与较新系统才识别的 manifest 属性会产生非阻断 lint 警告。
- Go 测试覆盖 TV 安装包独立发布、下载和损坏校验，以及原有队列、媒体、额度与发现功能。TV 的 `publish-apk -app tv` 校验 APK 真实包名 `cn.familyvideo.tv_app`，安装包列表新增第三项。

- 2026-10-26：`scripts/check.ps1` 全程退出码 0，Go `test ./...` / `vet ./...` 通过，家长端、儿童端、family_api、family_models、video_player_android 分析及现有测试通过（家长端有既有弃用 API 的 info 提示，按仓库脚本 `--no-fatal-infos` 运行）。

## 真机验收（待执行）

用户电视约十年前购买，具体型号与 Android 版本尚未确认；不能把模拟器或 lint 通过视为该电视已兼容。

1. U 盘安装并从电视桌面打开，确认图标、横屏、中文和安全边距。
2. 同局域网自动发现、单电脑直连、多电脑选择、手输地址与失败重试。
3. 720p 横屏、竖屏 H.264/AAC 的画面和声音；再验证现有 1080p 素材；4K/HEVC 不作为首版目标。
4. 上下切换、快速按键、确认暂停/继续、合集、返回与循环连播。
5. 断网/断服务恢复、删除当前/下一条、单个坏视频和整个列表失败后不会高速跳空。
6. 临时设短额度，验证当前自然结束后只播安静合集；未指定时停止；家长改规则和跨天后恢复。
7. 连续播放至少 2 小时、切换 100 次，观察进程内存是否持续增长；Home/待机后没有声音，唤醒后重新连接。
8. 播放前后检查应用私有 files/cache/databases/shared_prefs 目录，无媒体、封面、目录或历史文件。系统自身的安装/编译数据不属于业务缓存。
