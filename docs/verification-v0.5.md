# v0.5.0 页面与交互验证

两端版本 0.5.0+7。保持 Go 接口和免配对访问模式，本轮不修改服务端业务。

## 页面

- 家长：统一卡片、间距和输入样式；连接入口及状态；待同步/待审核/已发布计数；显式点击读取剪贴板；待同步列表；上传入口；任务筛选、折叠错误、重试/取消/前往视频库。
- 家长视频库：封面与播放入口、时长、发布状态、标题编辑与开关，宽屏双列。预览页增加进度拖动和正确的播放/暂停图标。
- 儿童：深色连接页；合集主题卡片；缓存视频信息和确认删除；个人页统计；按场景解释空状态；搜索缓存与大小写无关搜索、无结果提示。
- 顶部导航与播放器继续使用全屏约束，维持竖向滑动、原比例显示及电视按键。

## 状态与行为

- 两端刷新先获取完整结果再替换旧列表，避免第二个接口失败导致列表被部分清空。
- 家长仅在任务 queued/running 时每 8 秒轮询；忙碌和后台状态不请求，全部结束或页面销毁取消定时器。
- 儿童打开预览时暂停首页播放器；返回后只恢复原本播放的内容，手动暂停不会被取消。
- 搜索弹层自行管理输入控制器，动画关闭过程中不提前释放，避免进入播放页时的已释放控制器异常。
- 原有喜欢和离线缓存命名空间不变。

## 验证

- 家长 flutter analyze 无问题，6 项测试通过：离线收集持久化/删除、视频筛选/改名、合集编辑、完整家长页面任务筛选/错误展开/重试、处理中轮询及结束停轮询、320px 窄屏和 1.4 倍文本下长标题/长错误。
- 儿童 flutter analyze 无问题，9 项测试通过：手机/电视及横竖片源完整页面、导航返回布局、播放叠层操作、无配对地址连接、连接页与键盘/放大字体、缓存搜索、预览音频互斥及手动暂停恢复、刷新失败保留内容、缓存删除保留/确认。
- Go 16 项测试及 vet 通过，未改业务行为。
- 测试截图位于 runtime/ui/v05-*.png；已目视检查家长收集、任务、视频库、连接设置和儿童连接、合集、缓存、个人页。数据及封面均为测试内容，不使用家庭真实视频或登录信息。
