# v0.7.1 儿童端回切加载修复

儿童端版本 0.7.1+10，与现有 v0.7 服务兼容，家长端保持 0.7.0+9。

问题来自 FeedView.load 每次划走都 dispose 当前控制器，返回时重新 initialize/seek。保存进度只能恢复位置，不能保留播放器缓冲。

修复为页面内最近使用的 3 个播放器缓存：非当前暂停，回切复用同一控制器、ready Future、位置和原生缓冲，不重新 seek。超过容量、来源更换或失败时释放并重建；内存压力释放非当前，退出页面全部关闭。初始化中的条目也可复用，取消初始化等待时清理超时计时器，迟到结果不会播放隐藏音频。

验证：

- 儿童 flutter analyze 无问题，16 项测试通过。
- A→B→A 只创建 2 个原生播放器，回到 A 无重新初始化/seek，保持 34 秒位置；B 保持 18 秒，退出后两者均释放。
- 容量淘汰、内存压力、来源变化、HLS 回退控制器复用、失败重建、初始化中回切及淘汰取消通过。
- 其余布局、进度持久化、随机推荐和搜索路由播放互斥测试继续通过。
- 按项目约定执行 Go 25 项测试及 vet，通过；后端没有功能改动。

测试原生播放器通过平台假实现验证创建/播放/暂停/释放调用；不据此声称所有 Android 设备都不再出现网络缓冲。设备可回收缓冲，超过 3 条保留范围或页面已销毁后需要重新加载。
