提交家长提供的 https://v.douyin.com/3-8pa91hN60/，任务 cccbbd208c4d7c884f5b2d7853b41572 完成，auto_retries=0。全程为 API 提交 → F2 SDK 解析 → Go CDN 传输 → FFmpeg 处理 → 入库，没有手动文件搬入或审核 PATCH。
