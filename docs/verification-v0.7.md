# v0.7.0 验证记录

验证日期：2026-10-24。服务端 v0.7.0，Flutter 两端版本 0.7.0+9。

## 本轮行为

1. 家长视频库支持按标题/描述搜索、预览、修改标题和描述、确认删除。删除移除全部合集关联及对应完成任务，清理 MP4、封面、HLS 和原始文件缓存；文件仍被占用时保留持久清理任务。客户端 child 的管理请求被拒绝，既有免认证局域网边界保持不变。
2. 保留完整分享文案，F2 解析结果参与标题/描述生成，ffprobe 提取内嵌 title/description/comment；手填标题优先，文件没有内容元数据时使用文件名。按用户选择不包含语音和画面 AI 识别。
3. 新视频生成 HLS VOD 分片，儿童优先网络流媒体播放，初始化失败回退 MP4 Range，缓存下载仍独立。旧视频由后台单个补片，不在 API 请求中调用 FFmpeg。
4. 推荐、搜索、离线共用每服务器/每视频的本地进度。两秒周期、离页、后台保存，初始化 seek 后播放；接近结尾从头开始。
5. 启动时随机推荐，同会话刷新保留顺序、合并新内容，合集保持手工顺序。

## 自动化

- Go 25 项测试与 vet 通过：新增 v2→v3 迁移、元数据优先级/分享文案清洗、编辑描述、删除权限与合集/文件/任务清理、无法立即清理时持久重试、HLS 清单和 TS 读取/签名、旧片分片失败不无限重做。
- 共享 API：5 项测试、分析通过；旧服务缺少 managed 能力时明确提示升级，连接失败保留原地址。
- 家长：8 项测试、分析通过；增加描述编辑/搜索、取消删除与确认删除。
- 儿童：12 项测试、分析通过；增加视频/服务器进度隔离、持久恢复、完播重置、随机排序及刷新保序、HLS 数据源与真实控制器换页/回滑前 seek。模拟原生释放在 runAsync 中完成，避免把测试环境的异步释放误判成播放器阻塞。

共 50 项顶层测试通过。没有以测试占位图声称完成手机或电视解码验收。

## 独立服务验证

将 v0.6 验证数据库和视频复制到 runtime/verify-v07，通过 127.0.0.1:18765 启动新 EXE，不改家庭正在使用的数据。结果保存 runtime/verify-v07/result.json：

- schema v2 升至 v3，生成 1 份升级前快照。
- 旧的真实样例视频生成 63 段 HLS；首段 Range 4096 字节返回 206。
- ffprobe 经 HTTP 清单读取 H.264/AAC、1920×1440，FFmpeg 实际解码首帧成功。
- 通过 API 修改描述并删除隔离副本，目录清空且分片目录删除。
- 上传带内嵌 title/comment 的测试 MP4，自动得到 Ocean Tides / How tides form，处理完成后直接可见。

本轮没有重复请求抖音平台下载新样例；下载器新增的文案传递与缓存字段经过单元测试，既有自动下载实测见 v0.6 记录。

## 运行边界

MP4 与 HLS 同时保留，增加服务端存储。旧片补片失败仍可走 MP4 渐进播放；没有自适应多码率和网络断点续传。进度在当前设备保存，不跨设备同步。服务器删除不远程清除设备已有离线副本。

升级服务需停止旧进程再运行 bin/family-video.exe。新客户端要求 health 返回 library_mode=managed，避免在旧接口上静默丢失描述或删除操作。ADB 在本轮验收时没有连接设备，手机与电视原生播放仍需真机验证。
