# 家长端列表分页

收集箱首页保留收集表单、本地视频上传和两个列表入口，列表不再直接展开。

- 「查看待同步收集箱」打开二级页面。本机 SharedPreferences 中的待同步内容以 20 条为一批展示，上拉加载下一批；「同步 xx 条到家庭电脑」固定在底部安全区，数量为全部待同步条数，同步包含尚未滚动加载的条目。未连接、正在同步或列表为空时禁用按钮，未连接时提供连接入口。移除、系统分享和同步进度会更新当前页面。
- 「查看导入任务列表」打开二级页面。全部、处理中、失败、已完成筛选固定在顶部；每页 20 条，上拉加载下一页，下拉刷新，失败可重试。筛选在 SQLite 中先执行再分页，可以找到旧的任务；分页接口没有旧数组接口最近 200 条的截断。任务取消、重试、错误展开和进入视频库继续可用。
- 视频库每页 24 条。搜索标题/描述和四种排序在服务端执行，改变条件回到第一页；上拉追加，下拉刷新已加载的页，失败时保留已加载内容并提供重试。批量「全选已加载」仅选择当前条件下已加载的条目。合集编辑按需分批取得完整视频目录，不受视频库首屏 24 条的限制。

## HTTP 接口

`GET /api/videos?limit=24&offset=0&search=关键词&sort=newest` 支持 `newest`、`most_played`、`most_completed`、`most_watched`。`GET /api/tasks?limit=20&offset=0&filter=all` 支持 `all`、`processing`、`failed`、`completed`；处理中包含 queued/running。

带 `limit` 时返回 `{items,total,offset,limit,active}`。`total` 是当前条件的总条数，任务响应的 `active` 是全体 queued/running 任务数，用于监控未出现在第一页的任务。limit 有效范围 1–200，非法值回退为 24；负 offset 视为 0，越界返回空数组。相同排序值按创建时间和 rowid 倒序保持顺序。计数与当前页在同一读取事务中执行；分页期间新增、删除或任务状态变化可能改变后续页的位置，下拉刷新可重新对齐，客户端按 ID 合并以避免重复卡片。

不带 `limit` 时保留原有数组响应，儿童端、电视端及旧版网页调用方式不变；分页视频接口也遵循儿童安静模式。旧版电脑若仍返回数组，家长端回退为本机分页及筛选，任务范围仍受旧服务的 200 条限制。

家长端启动快照保存视频和任务的首屏目录，未加载的服务端页面需要家庭电脑在线；本机待同步收集箱仍可完整离线分页查看。

仅已处理成功并写入 videos 表的视频出现在视频库；导入与 FFmpeg 继续由 Go 后台 worker 执行。
